# Salão Agendamentos - MVP

Sistema de agendamento mobile-first para o Salão de Beleza da Comunidade (Projeto de Experiência Prática III).

## Tecnologias Utilizadas
- Python 3.11 / Flask
- SQLAlchemy / PostgreSQL
- Pytest (Testes automatizados)

## Regras de Acessibilidade e UX
- WCAG 2.1 AA (Botões de no mínimo 44px e contraste alto).
- LGPD: Coleta mínima de dados (sem necessidade de login para clientes).
